## 如何添加您的网站

欢迎交换友链！只需几步，你的站点就会出现在上面的友情链接中。

1. Fork [nameefef/friends-data](https://github.com/nameefef/friends-data) 仓库
2. 在 `data/friends/` 目录下新建一个 JSON 文件（文件名随意）
3. 按下方模板填写你的站点信息并保存
4. 提交代码，创建 Pull Request（PR）
5. 仓库的自动流程会校验格式，通过后我会审核合并，合并后自动部署

必填：`name`、`url`；`avatar` 可为 `null`；`description` 可选。头像建议正方形。

```json
{
  "name": "你的站点名",
  "avatar": "https://.../头像.png",
  "description": "一句话简介",
  "url": "https://你的站点/"
}
```

请同时在你自己的站点上加一条指向 `https://blog.easonyin.xyz/` 的友链。
